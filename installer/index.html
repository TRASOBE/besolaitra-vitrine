Be Solaitra

Le journal hebdomadaire, en application sur votre écran d'accueil.

Voulez-vous installer l'application Be Solaitra ?

Pour installer sur iPhone :
  1. Touchez le bouton Partager (le carré avec une flèche vers le haut).
  2. Choisissez Sur l'écran d'accueil.
  3. Touchez Ajouter.
Pour installer l'application :
  1. Ouvrez cette page dans Chrome (Android, ordinateur) ou Safari (iPhone).
  2. Ou ouvrez le menu du navigateur et choisissez Installer l'application / Ajouter à l'écran d'accueil.

L'application est installée. Retrouvez Be Solaitra sur votre écran d'accueil.
